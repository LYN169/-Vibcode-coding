## 开源版的构建修复

发现原武功镇构建插件对 `public/textures/` 所有文件调用 UTF-8 文本读取，把 PNG 当文本嵌入 HTML。原配置可以构建成功，但重新构建的网页出现乱码，不能正常显示规划页面。

本次仅在开源副本修改 `vite.config.ts`：

1. 仅内嵌 JSON、GeoJSON、CSV 文本；二进制纹理继续作为独立静态资源。
2. 转义内嵌 JSON 中的 `<`，避免数据内容破坏 script 标签。
3. 将 Vite base 对齐现有 `/sc-datav/` 资源前缀，使开发服务与生产目录一致。

源码主目录和已有线上部署未在本次操作中修改。完整来源与修改署名见武功镇项目 NOTICE。
