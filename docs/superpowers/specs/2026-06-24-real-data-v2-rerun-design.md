# Regional Potential Lab：真实数据 V2 重跑设计

## 已批准目标

本次执行严格以用户 2026-06-24 的九项要求为验收标准。原始数据目录只读；旧版 `outputs/processed` 不参与新一轮计算，只在新结果完成后用于差异对照。

## 数据与输出隔离

- 输入：配置文件所指向的原始 `data` 目录。
- 新输出根目录：`outputs/real_data_v2/`。
- 应用运行数据：`outputs/real_data_v2/app_data/`。
- 六个指定交付文件直接写入 V2 根目录。
- 不删除或覆盖旧版输出，确保 V1 与 V2 可复核比较。

## 经济表兼容

经济数据读取同时支持：

1. 旧宽表：`gdp_2019`、`gdp_2024`；
2. 新长表：`county_code`、`year`、`gdp`、`gdp_per_capita`、`gdp_density`。

`county_code` 始终按字符串规范化；长表以 `county_code + year` 校验唯一性。所有不可解析数值保留为 NA，不做插补或填零。

## 验证与测试

- 数据验证：县域数、主表行数、代码格式/缺口/重复、GDP 缺失、评分质量、错配分类和潜力指数可计算数。
- 空间分析：分别记录 Moran's I、显著性与 LISA 回填数；有效样本不足或依赖不可用时降级但不中断。
- 网页测试：2019、2024、对比模式，省/市/县筛选，地图图层，以及 CSV/GeoJSON 下载。
- 差异对照：仅在 V2 生成完成后读取旧版汇总结果，比较核心统计，不复用旧版中间数据。

## 验收标准

V2 根目录包含用户指定的六个文件；县域数应为 2891，两期主表应为 5782 行；网页默认读取 V2 应用数据，自动化与浏览器测试均有可复核记录。
