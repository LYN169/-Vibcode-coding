# 网站说明弹窗视觉修正设计

## 目标

仅调整“网站说明 / GUIDE”弹窗及其内部组件的视觉风格，不修改数据、指标、筛选和交互逻辑。

## 已选方案：深色运动科技风

- 弹窗背景：深黑半透明玻璃面板，与主页面背景一致；
- 边界：荧光绿顶部强调线、低透明白色细边框和深色阴影；
- 标题：白色高对比，说明文字使用浅灰；
- 折叠项：深色硬朗卡片，展开态增加荧光绿边界提示；
- 指标卡：深色底、白色数值、灰色标签；
- 警告信息：深色橙黄提示框，不再使用大面积浅黄；
- 状态标签：荧光绿浅底配黑色文字；非正常状态使用亮橙浅底配黑色文字。

## CSS 作用范围

所有规则必须限定在 BaseWeb Popover 容器内，避免影响：

- 主页面地图图层下拉框；
- 左侧栏普通控件；
- 页面主体提示框和结果表；
- Folium 地图 iframe。

状态标签 `.status-pill.live` 全局改为黑色文字与荧光绿底，因为该组合在浅色和深色容器中都具有更高可读性。

## 验收

1. 弹窗背景为深色，视觉上与主页面统一；
2. 状态标签文字为黑色且可清晰辨认；
3. 弹窗在 1440×1050 视口内不裁切；
4. 五个折叠项均可展开；
5. 地图下拉框与侧栏筛选器样式不受影响；
6. 浏览器控制台错误、页面错误、横向溢出均为 0。
