# 数据与资源说明

本次整理从作者当前运行项目复制案例使用的 GeoJSON、CSV、JSON、配色与卫星底图，便于重现已有展示；未额外从本机其他目录收集原始调查资料或汇报文件。

- `public/data/`：武功镇规划展示案例数据；其字段及内容以文件本身为准。
- `public/styles/`：项目现有 GIS 分类颜色快照。
- `public/textures/`：现有案例底图及范围文件。原目录未提供完整影像许可元数据，不能据此推断可任意转授权。
- `public/font/`、`public/model/`、`public/hdr/`、`src/assets/`：现有项目及上游演示使用的字体、模型和贴图资源，保留相应来源权利。

Apache-2.0 针对代码，不把第三方影像、字体、模型或规划数据重新声明为作者独有资产。复刻新项目时优先换成自己有使用权的数据和资源。本项目不是权威规划数据发布渠道，不能从页面判断法定审批状态。
