# 武功镇国土空间规划数字大屏 — 使用指南

> 版本：2026-05-26 | 面向普通用户、汇报人员、评审专家

---

## 1. 网页简介

本网页是**武功镇国土空间规划成果的三维数字大屏**，用于：

- 国土空间规划成果展示
- 规划方案汇报
- 农文旅资源导览
- 现状与规划用地结构对比
- 三维地图交互演示

网页基于开源三维大屏框架开发，集成了武功镇真实的 GIS 数据和 ArcGIS 配色方案。无需安装任何软件，在浏览器中直接打开即可使用。

## 3. 页面主要模式

网页包含两个核心模式，点击右上角按钮切换：

### 模式一：规划展示

顶部标题：**武功镇国土空间规划（2026—2040）**

默认显示：
- 规划用地（彩色填充地块）
- 规划边界（红色点划线）
- 左侧信息面板（规划基础指标、规划定位、发展关键词等）
- 右侧信息面板（现状用地结构、战略定位、用地变化对比图）

适用于：规划方案展示、用地结构汇报、专家评审

### 模式二：现状概况（景观资源导览）

顶部标题：**武功镇景观资源导览**

默认显示：
- 卫星底图（如果卫星图已加载）
- 规划边界（红色点划线）
- 景点点位（紫色发光圆点 + 名称标签）
- 左侧信息面板（区位条件、自然基础、人口现状、产业现状、农业基础）
- 右侧信息面板（文旅资源、文旅短板、人居环境、基础设施、交通现状、综合判断）

适用于：农文旅资源展示、景点导览、区域概况介绍

## 4. 主要交互说明

### 4.1 地图操作

| 操作 | 方式 |
|------|------|
| **旋转视角** | 鼠标左键按住拖动 |
| **缩放地图** | 鼠标滚轮（前滚放大、后滚缩小） |
| **拖拽平移** | 鼠标右键按住拖动 |
| **复位视角** | 点击底部工具栏第二个按钮（环形图标） |

### 4.2 模式切换

点击右上角的 **"规划展示" / "现状概况"** 按钮，在两个模式之间切换。

### 4.3 图层控制

页面底部中央有一排图层控制按钮：

**规划展示模式的图层**：
- **主图层**（单选）：规划用地 / 现状用地 / 无
- **叠加图层**（多选）：规划边界 / 规划道路

**现状概况模式的图层**：
- 卫星底图 / 规划边界 / 景点点位

点击按钮即可开启或关闭对应图层。激活的按钮呈橙色高亮。

### 4.4 查看用地信息

鼠标悬停到用地图斑或道路上，会自动弹出信息卡片，显示用地类型、面积、道路长度等信息。

### 4.5 查看景点详情

在现状概况模式下，地图上显示紫色圆点标记（景点位置）。**点击任意景点圆点**，会弹出详情卡片，包括：
- 景点名称
- 类型和地址
- 文物保护级别
- 详细介绍
- 推荐游览时长
- 标签
- 百科链接（如果可用）

再次点击同一景点或点击关闭按钮可关闭详情卡。

### 4.6 隐藏/展开左右信息框

点击底部工具栏**第三个按钮（星星图标）**，左右两侧的信息面板会滑出屏幕，地图占据完整视野。再次点击恢复。

> 注意：隐藏面板不会影响底部的图层控制按钮和工具按钮。

## 6. 汇报使用建议

1. **开场**：在规划展示模式，展示规划边界和用地布局，配合右侧指标说明规划范围
2. **用地变化讲解**：查看右下角"现状—规划用地对比"图表，说明变化趋势
3. **基础情况**：切换到现状概况模式，展示区位、人口、产业等背景信息
4. **文旅资源**：在现状概况模式，点击景点查看详细介绍，展示标签和推荐游览时长
5. **突出地图**：点击星星按钮隐藏信息面板，让地图填满屏幕
6. **道路与用地叠加**：在规划展示模式下，根据需要开关规划道路和现状用地图层

## 7. 常见问题

**Q：为什么有些图层默认关闭？**
为了画面清晰。规划道路和现状用地会遮挡主要信息，需要时手动开启。

**Q：为什么卫星底图只在现状概况出现？**
规划展示模式使用彩色用地表示，卫星底图会干扰颜色识别。现状概况模式需要卫星图来展示真实地貌。

**Q：为什么规划用地和现状用地不同时显示？**
两套用地图层叠加会导致颜色混乱和画面闪烁。一次只显示一套可以清晰对比。

**Q：为什么点击景点有时显示"暂无详细介绍"？**
说明该景点在景点详情表中暂无对应的详细介绍文字。这不影响点位位置显示。

**Q：网页卡顿怎么办？**
- 地图包含大量地块数据，建议在性能较好的电脑上使用
- 减少同时开启的图层数量
- 关闭不需要的视觉效果（点击底部工具栏第一个按钮）
