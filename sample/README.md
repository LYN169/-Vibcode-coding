# 示例数据

本目录包含 12 个完全虚构、相互邻接的县区，用于演示 2019/2024 联合尺度标准化、地区筛选、空间错配、变化计算、地图与导出。行政区名称、代码和数值均不对应真实地区。

2024 示例故意设置三种缺失情形：一个县仅缺 GDP，一个县缺三项经济统计但保留灯光，一个县同时缺三项经济统计和两项灯光输入。它们用于验证 NA 保留、动态权重、`partial`/`weak`、错配“数据不足”和导出空值，不代表真实县域情况。

重新生成示例数据：

```bash
python sample/generate_sample_data.py
```

示例中的 `county_code` 均带前导 `0`，用于验证字符串读取逻辑。
